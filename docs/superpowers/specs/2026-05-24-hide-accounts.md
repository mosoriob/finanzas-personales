# Hide/Ignore Accounts

**Date:** 2026-05-24
**Status:** approved

## Motivation

The user runs two Docker instances of the app (family + personal) syncing the same
bank credentials. The bank scraper pulls all accounts (e.g., two credit cards), but
each instance should only display the relevant ones. Hidden accounts should still sync
(balance + transactions stay fresh) but not appear in the UI.

## Schema Change

Add a `hidden` boolean to the `Account` model:

```prisma
model Account {
  id           Int           @id @default(autoincrement())
  name         String
  type         String
  bank         String
  balance      Int
  color        String        @default("#6366f1")
  hidden       Boolean       @default(false)
  createdAt    DateTime      @default(now())
  transactions Transaction[]
}
```

Migration: `npx prisma migrate dev --name add-account-hidden`

All existing accounts default to `hidden: false` (visible).

## Server Action

Add to `src/app/config/actions.ts`:

```typescript
export async function toggleAccountVisibility(id: number) {
  const account = await prisma.account.findUniqueOrThrow({ where: { id } });
  await prisma.account.update({
    where: { id },
    data: { hidden: !account.hidden },
  });
  revalidatePath("/config");
  revalidatePath("/");
  revalidatePath("/cuentas");
  revalidatePath("/transacciones");
}
```

## UI Queries to Filter

All pages that query accounts must add `where: { hidden: false }` except Config:

### 1. Dashboard (`src/app/page.tsx`)

```typescript
const accounts = await prisma.account.findMany({
  where: { hidden: false },
});
```

Hidden accounts excluded from total balance and account pills.

### 2. Cuentas page (`src/app/cuentas/page.tsx`)

```typescript
const accounts = await prisma.account.findMany({
  where: { hidden: false },
  include: { transactions: { where: { date: { gte: thirtyDaysAgo } } } },
});
```

### 3. Transacciones page (`src/app/transacciones/page.tsx`)

```typescript
const accounts = await prisma.account.findMany({
  where: { hidden: false },
});
// Also filter transactions to exclude hidden accounts:
const transactions = await prisma.transaction.findMany({
  where: {
    account: { hidden: false },
    // ... existing filters
  },
  include: { account: true, category: true },
});
```

### 4. Config page (`src/app/config/page.tsx`) — NO FILTER

Config shows ALL accounts (including hidden) so the user can toggle visibility.

## Config UI Changes (`src/app/config/ConfigClient.tsx`)

In the "Cuentas" tab, each account row gets a visibility toggle button:

**Current:**
```
🟢 Cuenta Corriente · BancoEstado · checking                    [🗑️]
```

**After:**
```
🟢 Cuenta Corriente · BancoEstado · checking               [👁️] [🗑️]
```

- Clicking the eye icon calls `toggleAccountVisibility(id)`
- Hidden accounts: eye icon becomes eye-off (👁️‍🗨️ → use EyeOff icon), row is
  visually dimmed (opacity-50 or similar)
- Hidden accounts are shown in a separate "Cuentas ocultas" section at the bottom
  OR simply greyed out inline — implementer's choice, keep it simple

## Sync Route — NO CHANGES

`src/app/api/sync/route.ts` is NOT modified. The sync continues to:
- Create new accounts (they default to `hidden: false`, so they appear)
- Update existing accounts' balances (even if hidden)
- Import transactions for all accounts (even hidden ones)

This ensures data stays fresh. If the user un-hides an account later, all historical
transactions are already there.
