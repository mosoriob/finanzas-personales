GIT WORKFLOW

- For each card, create a worktree:

      git worktree add .worktrees/<task-id> -b <type>/<task-id>-<slug> origin/main
- All edits inside the worktree. Commit frequently (after each green test).
- When done: push branch, open PR:
      gh pr create --base main --title "<card title>" --body "<summary>"
- Then call kanban_block(reason="review-required: <summary>") so the human reviews.
- On rejection (reviewer creates child card), reuse SAME worktree/branch — amend, don't start over.
- `git worktree remove` only after PR merges.
